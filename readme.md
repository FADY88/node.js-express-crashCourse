# Node.js & Express Learning Journey

This repository is my personal learning archive for the Node.js and Express course by Net Ninja on YouTube.

[the original repo of this course](https://github.com/iamshaunjp/node-crash-course)

## Overview

This project contains hands-on practice files and mini applications built while learning backend development with Node.js, Express.js, EJS templating, and MongoDB. The goal was to understand how a real web application works from the server side, starting with core Node.js concepts and progressing into full-stack app patterns.

The repository follows a step-by-step learning path from the basics of JavaScript runtime programming to building a blog web app with routing, views, middleware, and database integration.

## Learning Progress

### Core Node.js Fundamentals

- `lesson-2/` – File system operations, global objects, modules, and streams
- `lesson-3/` and `lesson-4/` – Creating basic HTTP servers and handling requests/responses
- `lesson-5/` and `lesson-6/` – Express basics, app setup, and route handling

### Express & Web App Development

- `lesson-7/` – Introduction to EJS views and partial templates
- `lesson-8/` – Static assets, CSS integration, and improved app structure
- `lesson-9/` – Blog model creation and data handling
- `lesson-10/` – Building a blog app with MongoDB integration and view rendering
- `lesson-11/` – MVC-style project structure using controllers, routes, and cleaner architecture

## Main Project Concepts Covered

- Node.js runtime and server-side JavaScript
- Express.js framework
- HTTP requests and routing
- Middleware and static file serving
- EJS templating and reusable layout partials
- Working with forms and user input
- MongoDB connection and Mongoose models
- CRUD flow for blog posts
- MVC architecture for scalable app structure
- Error handling and 404 pages

## Project Structure

The repository is organized by lesson number, with each folder representing a stage in the course. This makes it easy to revisit earlier concepts and compare how the app evolves from a simple server to a more structured Express application.

## Purpose

This repo reflects continuous practice and progress in backend development. It is not just a final project, but a learning journey showing how each concept builds on the previous one while following the Net Ninja Node.js and Express course.

This is a personal study repository created to strengthen understanding of JavaScript, server-side development, and full-stack web app basics using the Node.js ecosystem.
